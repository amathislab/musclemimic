# TERRA branch provenance

The `terra` branch starts from public MuscleMimic `main` and adds one squashed
commit containing the audited TERRA-compatible source tree. No private development
commits are ancestors of this branch. Unrelated research analyses and internal
cluster documentation were omitted.

The implementation retains the repository's Apache-2.0 license. Motion datasets,
SMPL-H body models, trained checkpoints, and authentication credentials are not
included. TERRA pins this branch by its public commit ID.
